# Mac 版功能

- 连接 Keeps Server，浏览统一资料库、精选及回收站，按目录和条件筛选照片。
- 按需展开服务器目录，保留展开与选择状态，支持右键菜单和键盘导航。
- 拖动分割条调整目录与图库宽度，目录滚动条自动隐藏。
- 图库按照片比例排版，滚动到底部自动分页，加载期间的翻页需求会在请求完成后继续处理。
- 选择照片并修改评分、旗标和标签，查看服务端预览与照片信息。
- 管理服务端来源追踪与扫描任务；回收站和停止追踪均不改动原片。
- 右键标记隐藏目录，子目录继承，隐藏目录及其子目录以灰色区分；开启菜单过滤时，全库及父目录不显示隐藏内容，进入隐藏目录或其子目录后可查看。标记保存在 NAS，菜单开关保存在当前 Mac。

- 与 iOS 共用图片缓存策略：各设备最多 5 GiB 磁盘缓存，自动回收近期未使用的预览；按显示尺寸加载图片，过期链接自动刷新一次。
